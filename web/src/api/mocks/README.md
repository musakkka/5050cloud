# web/src/api/mocks

Generated [MSW](https://mswjs.io) handlers for every REST route in
docs/SPEC.md section 11, so the console can run before `5050d serve --dev`
exists and tests can call the API without a server.

| File | What |
|---|---|
| `handlers.gen.ts` | Generated by `make gen-ts` (`pkg/api/internal/mockgen`). One handler per entry of `api.Routes`, answering with a deterministic fixture. Each JSON fixture uses `satisfies` with the type from `../types.gen.ts`, so `tsc` fails when a fixture and the contract disagree. Do not edit. |
| `browser.ts` | `startMocks()` starts the service worker (`public/mockServiceWorker.js`). `npm run dev:mocks` sets `VITE_MOCKS=1`, and `src/main.tsx` calls it before rendering. |
| `node.ts` | `server` for vitest (`msw/node`). |
| `handlers.test.ts` | Checks that every route has a handler and answers with 200, 204 or 302. |

The fixtures are deliberately plain ("example", `1`, one item per list). A
work package that needs richer data for a screen overrides a handler in its
own test or story with `server.use(...)` / `worker.use(...)` instead of
editing the generated file.
